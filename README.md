# a# 🛒 Análise de E-commerce - Projeto Nexus

Este projeto apresenta uma análise técnica e estratégica de dados de um e-commerce, focando em entender o comportamento do cliente e a performance de vendas.

## 📋 Conteúdo Principal
* Limpeza e tratamento de dados (Data Scrubbing).
* Análise exploratória de vendas.
* Dashboards com métricas estratégicas.
